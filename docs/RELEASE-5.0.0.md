# 芒果端辅助 5.0.0

发布日期：2026-10-21（Asia/Shanghai）

## 本版内容

- 自动欢迎改为随机延迟发送，默认范围为 `0.40–0.85` 秒。
- 设置页可独立关闭欢迎随机延迟，并自定义 `0–30` 秒范围；最小值不能大于最大值。
- 延迟期间会检查当前连接、会话、自动化开关和原始点击入口；断线、暂停、改设置或手动先点击都会取消，不会迟到补发。
- 每日自动欢迎 `10` 次总额度仍然保留，额度在实际发送前落盘；取消等待不占次数，发送失败或不确定仍占一次。
- 发布两个便携包：
  - `dist-5.0.0-with-data-final/芒果端辅助-便携版-5.0.0.exe`：携带当前用户数据快照，包括账号缓存、配置、记录、欢迎额度和桥接配对；仅在没有现有配置的全新数据目录中导入一次，保留已有账号文件。包含登录权限与配对凭据，仅供本人保管，不得公开分享。
  - `dist-5.0.0-clean/芒果端辅助-便携版-5.0.0.exe`：不携带个人数据，首次运行生成默认配置，不包含正版账号或桥接令牌。

## 数据处理

- 构建时旧 4.0 程序仍运行，本机数据尚未清空；关闭窗口可能只是隐藏到托盘，需在托盘选择“退出”。
- `tools/reset_local_data.ps1` 会检查程序已退出、备份并逐文件校验后，再删除这两个应用数据目录。下次打开无数据版会创建默认设置，不含个人监测名单、正版账号、桥接配对或历史记录。
- 两个版本仍使用同一套用户级数据目录。无数据版不携带数据，但不会主动删除电脑上已有的数据；先重置再打开它才是本机默认状态。有数据版不是账户密码重置工具，不会覆盖已有配置。
- 账号缓存目录为 `%APPDATA%\.mc-noclient`；应用数据目录为 `%APPDATA%\MC免客户端登录器`。
- 旧版本发布目录未覆盖或删除。
