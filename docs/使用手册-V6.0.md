# 芒果端辅助 V6.0 使用说明

适用桌面端 6.0.0，桥接 Mod 1.4.0。2026-10-24。

## 升级与连接

退出旧版本后启动 V6.0 未签名便携版。旧账号、服务器、配对与欢迎计数继续使用；不要同时运行多个版本。未签名不代表已完成发布者验证，勿为运行修改系统信任根或应用控制策略。

独立模式选择账号和服务器后连接；游戏桥接继续复用已进服游戏，不另行登录。Mod 沿用 1.4.0，不要寻找版本号为 6.0 的 JAR。

## 服务器设置

未连接时先在左侧选择服务器，再打开设置，核对顶部服务器地址。消息动作、自动收购、零点命令、快捷指令、监测名单、聊天筛选和重要提醒按当前服保存。

升级前已保存的服务器保留原设置，并在关注页显示提示。新服务器的自动发送功能默认关闭，按需明确开启。连接或重连期间不能切换正在使用的配置。

在线玩家页可为玩家启用发言监测；在设置中开启“已监测玩家发言”后才会将其发言列为重要提醒。

## 关注

“动作记录”显示本次运行在当前服观察到的动作，展开一项可查看各阶段原因。没有可执行入口的普通消息不会产生动作。未连接、对应功能关闭和暂停状态显示在上方。

“已提交”不等于成功。只有明确服务端回执才显示确认；超时或断线时，已经提交的红包可能显示结果未知。欢迎仍以服务端结果为准，软件不自动重试。

“查看原消息”定位到只读消息，不恢复历史操作按钮。记录超出预算或已清理时会提示找不到；大记录库可再次点击继续查找。

“未查看期间”统计本次运行窗口隐藏或失焦时实际观察到的重要消息、断线与动作；涵盖所有连接。断线、休眠期间没有观察到的信息不会补造。

## 重要提醒

在设置中分别开启“有人提到我”“已监测玩家发言”或“维护结束或连接恢复失败”。系统通知独立开启，默认关闭；默认不展示正文。

提醒在 3 秒窗口合并，通知不播放声音。静音时段只记重要未读，不弹系统通知；开始和结束相同表示全天静音。便携版系统展示依赖 Windows 环境，失败时在关注页查看提醒。点击“标为已读”清除本次运行所有服务器的重要未读。

监测只依据实际发送者或可识别的聊天前缀，不保证支持全部插件昵称格式。提到玩家不等于该玩家发言。

## 离线演练

留空并开始演练：使用当前服及在线账号最近最多 200 条记录。输入多行文字：测试这些消息是否会命中提醒；纯文本没有点击入口，不能用于凭空测试领取命令。

演练不连接服务器、不发送命令、不改变真实欢迎额度；延迟取中间值，欢迎计数使用演练开始时的本机快照。结果是按当前设置的模拟判断，不预测服务器执行或奖励到账。

## 后台、休眠与记录

后台运行方式仍在“设置 → 账号 → 关闭窗口时”选择。托盘隐藏后减少显示工作，连接和必要自动化继续运行。

电脑休眠会取消旧动作，唤醒后需手动重连或重新启动桥接，不补发旧动作。暂停开关不会阻止你明确执行的普通手动聊天。

聊天、日志、事件、缓存最多保留 7 天且总计 128 MiB，超额清理最早文件。关注页最多显示当前服最近 100 项动作和重要消息；完整关注视图不跨重启恢复。

排错请提供版本、模式、时间与脱敏诊断报告，不公开账号文件、令牌、配对 JSON 或私人数据包。
