## 指令监测精简

- 出站监测仅保留当前连接实际提交的普通/带签名指令包，展示以 / 开头的真实指令，不猜测菜单绑定，不自动重放。登录等常见敏感参数仍在两端隐藏，过长参数不显示截断的假完整命令。

- 只指监测范围，不代表清空其他运行日志。保留 Nan_Koi 聊天留存、红包十秒明细汇总、按领取人数触发/随机互斥、在线玩家、午夜策略和自动钓鱼适配。没有新增对猜测命令的自动试发。

## 槽位绑定命令核查

已经只读检查本地实际 26.2 点击包字节码与当前项目资料，并通过 GitHub 官方仓库 API 查看菜单插件 DeluxeMenus 的 ActionType / ClickActionTask 实现。点击包没有对应命令字符串字段；该插件的玩家命令、控制台命令与直接打开菜单都可由服务端处理。但不能据此确认目标服务器使用这个插件。

没有取得该服实际菜单配置，也没有找到可核实的该服公开槽位映射，因此未实现“槽位反推指令”，没有把通用工作台/商店命令当作已发现结果。真实确定方法、必要资料及限制见 COMMAND_MAPPING_LIMITS.md。当前客户端 Mod 不能凭空获取服务器未下发的绑定关系。
