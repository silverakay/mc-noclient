# 芒果端辅助 V6.3

日期：2026-10-25（Asia/Singapore）。内部版本 6.3.0。未签名版本。配套桥接 Mod 1.6.0，Minecraft 26.2。

## 双开桥接

- 修复两个辅助进程使用同一 `bridge-pairing.json` 时，第二个监听因 `EADDRINUSE` 失败的问题。原端口已占用时，由系统分配独立回环端口，不关闭原窗口、不抢占其他进程、不轮换原配对令牌。
- 每个窗口在本机数据目录的 `bridge-listeners` 下发布独立、原子替换的短期监听记录。记录只含令牌指纹、端口、进程号、已绑定游戏账号、忙碌状态及有效期，不含令牌。停止只移除自己的记录；异常退出记录过期失效，后续启动只清理已退出进程的过期记录。
- 新 Mod 通过导出配对中的绝对 `discoveryDirectory` 路径读取本机记录，优先匹配游戏账号，未绑定窗口可接受首次配对。自动交接窗口只接受原来被踢的同账号。每个窗口绑定后不被其他账号抢占，聊天、菜单、下线和指令仍沿用原会话校验。
- 配对握手包含当前游戏用户名；错误账号、第二个连接、坏令牌和过期记录不会改变已连接游戏，也不触发游戏登录或重连。两个匿名窗口首次启动时可能按可用顺序配对，实际账号仍决定各自设置。
- 单窗口旧配对仍兼容原固定端口。**双开必须同时更新软件与 Mod，并从 V6.3 重新导出一次配对到各游戏实例的 `config/mc-noclient-bridge.json`。** 新配对不需要重复生成令牌，软件窗口启动顺序变化也不需再次导出。旧 Mod 不支持新端口发现。
- 发现目录仅适用于当前电脑和用户数据路径；迁移到另一台电脑或更改数据目录后需重新导出。不公开上传配对文件。

## 客户端崩溃诊断

本机 `E:\MineCraft\minecraft-run\.minecraft\versions\26.2-Fabric 0.19.3\crash-reports\crash-2026-10-25_12.51.28-client.txt` 显示：

- 顶层为 Voxy 的 `LoadException: Force crashing due to exception during on game join`。
- 根因为 `org.rocksdb.RocksDBException: Failed to create lock file`，冲突位置为该游戏目录 `.voxy/saves/.../storage/LOCK`。
- 两个游戏进程共用同一 Voxy 数据库，第二个无法取得独占锁。这与辅助端的 TCP 端口冲突是独立问题，不能声称更新桥接后此崩溃已修复。

建议为两个账号创建独立 PCL 游戏实例并启用游戏目录隔离，确认启动参数 `--gameDir` 不同、Voxy 存储也不共用同一目录。另一选择是在专用的第二实例停用 Voxy。**不要删除仍被游戏使用的 `LOCK` 文件或共用中的数据库。** 本轮未关闭用户游戏、未修改或删除 Voxy 配置、缓存和游戏目录。
