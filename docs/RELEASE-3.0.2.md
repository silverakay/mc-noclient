# 芒果端辅助 3.0.2

发布日期：2026-10-15。

## 修改

- 纯 2D 界面启动时关闭硬件 GPU 加速，并将软件 GPU 放入主进程，避免为简单工具界面维持约 55–60 MB 的独立图形进程开销。
- 可点击富文本动作参数限制为 4096 字符，防止异常服务器消息把动作索引和 DOM 属性同时撑大。
- 超过 512 个富文本片段或 16384 个正文字符的单条消息改为一个完整纯文本节点，正文不截断，但不为异常复杂消息创建数千个按钮/节点。
- 待渲染聊天队列同时受条数和 2 MiB 字符预算约束，高峰期只丢弃最旧的待显示消息，不阻塞网络、红包判断、桥接或自动化。

## 保持不变

- 聊天、日志、红包自动领取/人数触发、欢迎、零点命令、在线玩家、服务器菜单只读预览、TAB 补全和游戏桥接行为保持不变。
- 正常长度的富文本、点击领取入口、`suggest_command` 填入输入框和桥接动作仍按原路径处理。
- 不修改账号缓存、服务器配置、桥接配对或用户游戏目录；不需要重新配对或更换桥接 Mod。
