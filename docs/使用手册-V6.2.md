# 芒果端辅助 V6.2 使用说明

本版为未签名版本，内部版本 6.2.0。沿用桥接 Mod 1.5.0（Minecraft 26.2）。

## 两个账号分别设置

1. 在账号区域选择并切换到第一个账号，选择服务器，再打开右上角设置。
2. 设置顶部显示当前账号与服务器。桥接下线、消息动作、通知等设置只保存到这个账号；同一账号内仍分别保存不同服务器的动作设置。
3. 断开连接或停止桥接后，再切换到第二个账号设置。每次切换会恢复该账号已有设置；旧版设置作为初始值继承，不删除旧数据。
4. 双开时，分别在两个窗口登录各自账号。另一个窗口改选账号或保存设置，不会改变当前窗口已选账号，也不会覆盖当前账号的设置。

连接、桥接或重连过程中不能直接切换账号，须先断开。若打开设置后账号或服务器发生变化，请关闭并重新打开设置。

## 独立连接重连

- 重连只使用本次连接原账号的 UUID 和凭据，不再读取另一窗口的默认账号选择。
- 临时网络错误按该账号的重连策略重试；原账号凭据失效、被移除或返回不同身份时停止，不借用另一个账号。
- 停止后请手动为原账号重新授权，再明确点击连接。退出当前账号不会自动登录其他已保存账号。

## 多个玩家在线就下线

1. 使用游戏桥接模式，并确保游戏安装了桥接 Mod 1.5.0。
2. 打开设置中的“桥接下线”。可从在线玩家列表勾选多个玩家，也可搜索名字缩小候选范围。
3. 对离线玩家，输入完整玩家 ID，点击“添加”或按 Enter。目标列表显示已选玩家，可点击相应移除按钮删除。
4. 开启“任一目标玩家在线时退出游戏服务器”并保存。支持最多 16 位目标，至少选择一位。ID 仅允许 1–16 位英文、数字和下划线，忽略大小写去重。

其中任意一位出现在游戏实际在线名单中即可触发；多个目标同时在线也只执行一次。目标已经在线时保存启用，也会立即核对并触发。聊天提及、@ 和上线文字不会作为下线依据。

触发后停止自动动作、桥接监听与独立重连。没有成功回执时显示“下线未确认”，不擅自重试。此功能不关闭 Minecraft 进程，不控制其他 Mod 或启动器的自动重连。

## 更新与数据

- 使用 `dist-6.2.0-unsigned` 内的未签名便携版 EXE，或完整 `win-unpacked` 目录内的 EXE。目录版须保留同目录运行库。
- 旧发布目录、本机账号、配对文件和历史数据不删除。公共包不附带个人凭据与配对秘密。
- 本版没有发布者签名验证。不安装信任证书、不修改 Windows 安全控制；若系统阻止启动，不把打包成功当作可运行的保证。
