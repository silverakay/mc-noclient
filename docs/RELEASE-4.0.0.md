# 芒果端辅助 4.0.0

发布日期：2026-10-19（Asia/Shanghai）

## 本版内容

- 聊天记录改为 7 天滚动归档，不再以固定条数删除聊天记录。
- 聊天界面只维护有界 DOM 窗口；滚动到顶部或点击“加载更早聊天”时，从归档按批次加载，避免无限聊天造成渲染卡顿和内存增长。
- 运行日志界面保留数量可设置为 `200`、`400` 或 `800`，默认 `800`。日志磁盘归档不受显示条数影响。
- 聊天、运行日志、诊断缓存分别位于自定义记录目录下的 `chat/`、`logs/`、`cache/` 子目录。默认目录为应用数据目录下的 `records/`，设置中可选择其他目录。
- 启动时和每小时清理超过 7 天的记录与缓存文件。
- 在线玩家列表每行新增“监测/取消监测”，可指定任意在线玩家监测其发言。旧配置没有新字段时默认保留 `Nan_Koi` 监测行为。
- 设置中可一键暂停全部自动化动作；暂停只影响自动红包、自动欢迎和零点命令，不影响手动操作或连接。
- 设置中可生成脱敏诊断报告、打开数据目录和重载界面，便于排查问题且不包含账号凭据、服务器密码或桥接令牌。
- 保留 3.0.2 的 GPU、富文本、点击动作和渲染队列内存约束；桥接 Mod 不变，仍为 1.2.0。

## 配置兼容

- 原账号、服务器、红包、重连、桥接配对和其他设置继续使用。
- 新增 `display.logLimit`、`storage.path`、`storage.retentionDays`、`monitoredPlayers` 和 `automation.paused`，旧配置会自动补齐。
- `storage.path` 只接受绝对路径；无效或空值回落到应用数据目录下的 `records/`。
- 账号凭据仍由原账号模块保存在原位置，不会因为记录目录迁移而移动或暴露。

## 验证

- `node src/run_all_tests.js`：全部离线套件通过。
- `node tools/chat_ui_smoke.js`：桌面 UI 冒烟通过（需要本地安装 Playwright）。
- `node tools/tab_performance_test.js --electron`：真实 Electron 页签与消息压力回归通过（需要本地安装 Playwright）。
- 未连接实服、未启动用户游戏、未读取或复制凭据/配对令牌。
