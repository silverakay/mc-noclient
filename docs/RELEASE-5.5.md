# 芒果端辅助 V5.5

更新日期：2026-10-22（Asia/Shanghai）。内部版本：5.5.0。桥接 Mod 保持 1.4.0，无需更新。

## 手动与自动获取分离

- 手动获取不再受当天已成功 1 次的限制，已有快照时按钮为“重新获取”。每次都实际读取系统收购和农作物收购，不以缓存直接返回成功。
- 自动获取每天最多成功 1 次；手动刷新不重置、不增加也不消耗自动额度。若当天自动尚未完成，之后仍保留一次自动获取机会。
- 界面分别显示“今日自动 0/1 或 1/1”与“手动成功 N 次”。手动不设每日次数上限，但同一时刻仅一轮采集，重复点击不会并发。
- 手动成功后原子更新当天完整价目表及时间，两类均完成并写盘成功后才增加成功次数。刷新中保留上次数据；超时、菜单异常或写盘失败时保留上次快照及次数，错误可见并能再试。
- 兼容 V5.4 及以前的成功记录：原 count=1 保留为已完成的自动额度，手动成功次数从 0 开始；升级无需删除账号、菜单记录或用户数据。
- 记录沿用 version=1 并增加 autoCount、manualCount、source 字段，旧目录和历史日期记录保留。跨天按服务器及账号分别重置当日计数。
- 保留独立连接后台菜单处理及桥接成功流程；不自动点击商品，不进入鱼店。暂停自动化、签到处理中、光标物品及菜单占用等保护不变。
