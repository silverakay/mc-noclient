# 芒果端辅助 2.4.14

## 界面与名称

- 软件、窗口标题、便携/安装包和快捷方式改名“芒果端辅助”。内部 appId/name 和原固定数据目录不变，继续读取原账号、服务器、在线记录、欢迎预算、零点去重与桥接配对；不搬迁或清空用户文件。
- 资源监控移到左下角，取消 CPU/内存曲线，显示本软件占用 `实时 / 本次运行最高`。内存百分比以整机物理内存为分母，悬停可看实时/峰值字节；保留折叠进程明细，设置开关仍可隐藏。峰值在主进程维护，切页签、后台或窗口恢复不清零，退出后重新启动才清零。
- 删除桌面 Steve/离线用户名框与离线登录开关。独立连接只用已登录的正版账号，桥接仍复用游戏正版连接而无需软件账号认证。旧命令行与协议层的离线测试兼容能力未删除，但不再由桌面界面使用。
- 服务器列表在左栏剩余高度内滚动，保留 2.4.13 的消息按帧滚动、屏幕外布局跳过、历史位置与增量名单修复。

## 关闭窗口

设置“关闭窗口时”可选“结束程序 / 后台运行（托盘）”，默认仍结束程序。后台选项关闭时隐藏同一窗口并保留当前连接、自动领取与定时任务，不关闭游戏，不创建第二次登录。
任务栏通知区托盘点击或“显示主窗口”可恢复；“退出程序”明确终止，执行原断线/监听/定时器清理。托盘创建失败则正常退出，避免留下没有恢复入口的进程。普通最小化行为不变。后台不能让已关掉的游戏连接继续存在，也不会阻止系统休眠。

## 红包随机延迟

默认每个实际领取命令随机等待 0.40–0.85 秒。在设置“消息动作”中自定义最小/最大秒数，支持 0–30 秒、0.01 秒步进，最小不得超过最大；两值相同为固定延迟，均为 0 为无延迟。无效范围在界面和主进程保存端均拒绝，旧配置缺少范围时补默认。
仅服务端真实红包末尾 `run_command` 自动领取入口延迟，口令 `suggest_command` 仍只填输入框，欢迎和零点命令不加此延迟。等待时立即去重并计入每分钟限速；断线、会话变化、关闭自动领取、改延迟或对应手动领取取消待发送动作，不重排、不补发。手动领取不同重复 ID 也不会随后再自动发送。
发送前重验当前连接、游戏阶段、动作会话/存在、自动开关与冲突 Mod。计时器比预定时刻迟到超过 2 秒时跳过，防休眠后补发旧领取。执行后仍按原确认/拒绝/30 秒未确认规则，不把本地回执当到账，不重试。延迟可能降低红包抢到的概率，不保证服务端发放或规则许可；本轮未向实服测试发送。
