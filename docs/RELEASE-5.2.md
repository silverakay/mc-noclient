# 芒果端辅助 V5.2

更新日期：2026-10-22（Asia/Shanghai）。内部版本：5.2.0。桥接 Mod：1.3.0。

- 在聊天、运行日志、在线玩家之后新增“每日收购”。系统收购和农作物收购分表显示价格、服务端趋势、出售限量、剩余数量和采集时间，不采集鱼类。
- 独立连接发送 26.2 中等效于 Shift+F 的潜行输入、交换副手和恢复输入，读取服务器菜单；游戏桥接使用同一套受验证导航，需要配套 1.3.0 Mod。
- 上线后当天次数为 0 时自动获取；零点命令提交后等待签到界面结束再获取。签到命令提交不等于签到成功，不会代替用户点击签到奖励。
- 两类价目表都读取并持久化成功后，按本地日期、服务器和账号记为 1/1；重连和重启后复用当天记录，跨天重新获取。失败保持 0，可以手动重试，不循环点击未知菜单。
- 当前实测布局为每类 15 个商品位；不完整的增量快照继续等待，不将半份价目表记为成功。若服务器调整商品位，停止采集并保留 0 次。
- 仅点击已核对标题、格号和名称的菜单导航，不点击收购商品、不出售物品、不进入鱼店。用户打开的其他界面不被自动接管。历史日期 JSON 保留在数据目录的 daily-purchase 中。
- 单价与趋势取自服务器 lore；售出数量是采集时快照，当日不再次采集，所以不会实时反映后续交易。

## 验收与发布

保留旧版本目录和用户数据，依赖版本不变。生产构建仍要求 `forceCodeSigning: true`。
缺少获授权的受信任代码签名凭据时，不生成正式 EXE，不声称 Windows 发布者拦截已解决。
离线协议测试和 Mod 编译不能替代真实服务器采集验收。
