# 芒果端辅助 V5.4

更新日期：2026-10-22（Asia/Shanghai）。内部版本：5.4.0。桥接 Mod 保持 1.4.0。

## 独立连接后台采集

- 将独立连接的每日收购菜单与手动菜单展示分开。采集中的菜单、失败时的菜单及同一菜单后续刷新均不再弹出软件窗口。新打开的手动菜单仍按原方式显示。
- 移除“采集失败后主动弹出当前菜单”的逻辑。错误保留在每日收购页面和运行日志中，不以弹窗作为下一步操作入口。
- 独立连接使用固定的 700 ms 导航等待；高频物品刷新不再重新计时。到点读取最新窗口状态及格子内容，再校验唯一入口，按最新 revision/stateId 提交，不复用过期快照。
- 一个菜单代际提交过导航后只等待下一菜单，不因同页刷新重复点击。相同容器编号重新打开仍按新 token 处理；暂停、断线、日期或会话变化取消旧任务。
- 失败时仅在可确认是本次自动采集的已知菜单、无光标物品、无待确认点击时关闭容器；没有执行过物品点击的自动初始菜单也可安全关闭。未知菜单、光标占用或待确认点击保持不动，不自动重试。
- 增加就绪诊断：状态、容器类型、服务端状态号、已收到/预期格数、光标是否确认、是否可点击、待确认点击、入口数量、整包/单格/忽略单格数量及最近整包窗口编号。变化日志限频，超时给出最终状态。
- 两类完整保存后才记为当日 1 次；失败保持 0。账号、服务器、日期隔离及原用户数据格式不变。旧发布目录保留，不附带私人账号和配对快照。

## 桥接边界

桥接端 Mod 和成功采集时使用的菜单等待、导航及读取流程不变，无需重新安装 Mod 1.4.0。新增独立连接逻辑按客户端能力区分；包含桥接双商店回归测试。

## 验收范围

本次针对用户观察与代码中确认存在的两处问题修复，但不将“弹窗一定导致服务器菜单卡住”写成已验证事实。
若服务端未提供完整容器数据、光标状态未知或菜单无法点击，仍会安全停止，并通过新增诊断显示具体阻塞条件，不伪造就绪或跳过保护。

构建沿用用户明确要求的未签名测试配置：`dist-5.4.0-unsigned/芒果端辅助-未签名测试版-5.4.0.exe`。
正式构建保留 `forceCodeSigning: true`。本机隔离启动与离线回归不能替代目标服实际采集验收，不自动登录或挤掉游戏会话。
