# 芒果端辅助 V5.3

更新日期：2026-10-22（Asia/Shanghai）。内部版本：5.3.0。桥接 Mod：1.4.0。

## 采集菜单修复

用户反馈 V5.2 在 20:22:29 开始采集、20:22:41 超时，实际进入公会功能菜单。
本地日志确认该次使用独立连接，但旧版没有记录各阶段实际菜单标题，因此不能据此断言所有错误发生在哪一格。

只读参考用户提供的 `menuwatch-1.0.0+26.2.jar` 同目录源码、18:50 成功采集记录和 cmdtree 源码，没有安装、修改或启动这些调试 Mod。

- 独立连接不再同一轮连续发送潜行、换副手、取消潜行：按下潜行后等待 200 ms，再换副手，继续保持 150 ms 后释放。断线、重新配置、暂停或菜单变化时取消未执行动作，不补点。
- 游戏桥接按 MenuWatch 的方式分游戏 tick 按住潜行，确认玩家和已发送的输入均为潜行后触发换副手键，再延后松开；取消、超时和会话变化均释放模拟按键。使用当前换副手键绑定，不固定键盘 F。
- 上线自动采集延后至 15 秒，与成功脚本一致，已有菜单时继续等待，不接管用户界面。
- 每个导航步骤先核对菜单标题，再在本次商店区域查找唯一的精确入口名称，不再固定点 23、29、33、20。原位置被公会按钮替换时不会点击它，重复同名入口也会停止。
- 收到公会或工会菜单立即停止，即使物品还没加载也不继续盲等。日志记录实际窗口标题、导航目标、实际格号、每类读取数量；超时会说明预期菜单和最后收到的实际界面。
- 桥接像 MenuWatch 一样从 `ClientboundOpenScreenPacket` 读取真实标题，保留同容器编号重复打开时的代际，防止只凭旧屏幕标题误认页面。
- 保留只读系统/农作物采集、不点商品、不进鱼店；两类完整保存后才记 1 次。数据目录及记录格式不变，旧 V5.2 包和用户数据均保留。
