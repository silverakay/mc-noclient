# 芒果端辅助 V6.4

日期：2026-10-25（Asia/Singapore）。内部版本 6.4.0。未签名版本。配套桥接 Mod 1.7.0，Minecraft 26.2。

## 游戏下线后独立接管

- 新增“设置 → 连接 → 游戏下线后独立接管”，按账号、服务器分别保存。
- 默认“仅桥接下线成功后”：目标玩家触发桥接下线，游戏返回成功回执或同会话明确离线证据后，停止本窗口桥接并自动使用同一账号连接原服务器。不再默认保持停机状态。
- 选择“关闭”保留原行为，游戏下线后辅助停止，不另行登录。
- 选择“普通游戏下线后也接管”，无需启用目标玩家规则，普通游戏退出服务器或网络连接结束且 Mod 仍运行、明确上报离线时，也能接管。不会主动使游戏下线。
- 接管始终需要当前游戏账号已保存的正版凭据。按游戏身份锁定原 UUID，静默续期时不改另一窗口的默认账号；凭据缺失、重复身份、返回 UUID 不一致时停止并提示，不借用别的账号或弹授权浏览器。
- 独立模式保存成功后才发起连接；自动接管不重复入服问候或预设业务指令。初次失败不会新增无限重试；独立连接成功后沿用该账号既有重连与自动化设置。桥接下线功能本身仍仅在桥接模式生效。

## 安全边界

- Mod 1.7.0 记录已在线会话对应的游戏网络连接，仅在该连接确实关闭后携带原会话 ID 报告 `gameDisconnected`，并协商 `offlineState` 能力。游戏重新配置、进入菜单前的未就绪阶段、初始主菜单、本地桥接掉线都不算明确离线。
- 游戏完全关闭或崩溃造成桥接 socket 直接断开而没有离线报告时，不猜测游戏状态，不自动登录。普通下线接管不能把“Mod 通道断了”当作游戏已下线。
- 下线失败、超时、旧会话回执或等待时游戏换会话不会触发接管。手动断开、退出账号、程序退出、休眠、暂停自动化或关闭接管会阻止尚未完成的切换与迟到认证结果。
- 不指挥其他 Mod；游戏自动重连可能与独立连接互相挤下线，使用接管时应关闭其他游戏自动重连。桥接下线后仍保留原停止自动桥接标记，不自动在桥接与独立连接之间循环；再次使用游戏时可手动启动桥接。

## 更新与交付

- 新产物位于 `dist-6.4.0-unsigned`。自行退出旧辅助，再使用 V6.4；游戏退出后用 `mc-noclient-bridge-1.7.0+26.2.jar` 替换旧桥接 JAR，不同版本不能并存。
- V6.3 已导出带 `discoveryDirectory` 的配对可沿用，无需换令牌；更早的固定端口配对仍需重新导出以支持双开。未自动替换游戏 Mod、未修改真实账号、配对或游戏数据。
- 继续 `build.forceCodeSigning: false`，明确标注未签名，不宣称发布者验证，不安装证书、不改变 Windows 安全策略。保留旧发布目录，不更改依赖版本。公共包不含账号凭据、配对令牌或私人数据快照。
- 本地与离线检查不能替代真实服务器环境下的下线、接管及多 Mod 共存验收；本轮不连接目标服务器、不向实服发送聊天或指令。
