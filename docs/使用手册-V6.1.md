# 芒果端辅助 V6.1 使用说明

桌面端 6.1.0，桥接 Mod 1.5.0，MC 26.2。2026-10-24。

## 更新

1. 退出旧辅助软件与目标 Minecraft 实例，保留原数据。
2. 使用同目录的 V6.1 未签名便携版。
3. 将目标游戏实例 `mods` 中旧桥接 JAR 移出备份，换成 `mc-noclient-bridge-1.5.0+26.2.jar`，不要同 ID 多份共存。原配对 JSON 不用重新导出。
4. 重启该实例、进入服务器，在辅助软件中手动启动游戏桥接。

本轮没有自动替换你的游戏文件或关闭当前连接。仅更新 EXE、不更新 Mod，聊天桥接仍可用，但新下线功能不可用。

## 玩家在线就下线

1. 在桥接当前服务器的“设置 → 桥接下线”中勾选“指定玩家在线时退出游戏服务器”。
2. 在“玩家 ID”选择当前在线玩家，或填写其准确 ID，例如 `mango0v0`。
3. 保存设置。若此人已经在线，保存后就会执行；若暂时离线，则在后续实际名单出现时执行。

退出的是你当前游戏的服务器连接，不是对方，不会修改你的账号名。正常完成后，软件停止桥接和重连，只有你手动再次启动才恢复。数字 `0` 与字母 `O` 是不同 ID。

聊天里提到这个名字、@、封禁广播或上线文字不会触发退出；以 Mod 实际在线名单为准。对方离开、旧会话、旧请求或能力不支持时不强行执行。未确认则记错误、不重试。

本功能不控制其他 Mod、客户端或启动器的自动重连设置。若安装了这类扩展，需自行关闭其重连。

## 关注与监测

打开“关注”即自动已读，无需再点按钮。窗口隐藏、失焦时不清除新未读。只处理当前服已经展示的消息，其他服务器未读仍保留。

离线演练已删除，升级迁移提示不再常驻展示。原动作过程、重要消息及未查看摘要保留。

“在线玩家”中按需开启玩家监测；其发言、被提到、@ 与相关封禁广播会记录到“运行日志 → 玩家监测”。该记录不等于目标玩家真的在线，也不会单独触发下线。

其他账号登录、配对、聊天、自动化额度、后台与存储预算沿用 V6.0。不要公开账号、配对令牌或私人数据目录。
