# 芒果端辅助 V6.1

日期：2026-10-24（Asia/Singapore）。内部版本 6.1.0。配套桥接 Mod 1.5.0，Minecraft 26.2。

## 指定玩家在线就下线

- “设置 → 桥接下线”新增开关和目标玩家 ID，可从本次在线名单选择或手动填写离线玩家。按当前服务器保存，默认关闭，不更改自己的账号 ID。
- 仅桥接模式依据游戏实际 TAB 在线名单判断，不根据聊天、@、封禁广播或普通上线文字猜测。名单沿用现有约 3 秒上报周期，不新增高频轮询。
- 目标已在线时启用或保存设置也会触发；ID 忽略大小写但精确匹配，不混淆数字 0 和字母 O，也不匹配名字子串。
- Mod 执行前核对协商能力、配对通道、会话和请求截止时间，并再次核对目标仍在实时名单中；使用本地官方 26.2 暂停菜单相同的 `Minecraft.disconnectFromWorld` 游戏退出路径，不发送 `/quit` 或猜服务器命令。
- 触发时取消等待动作，停止独立重连与自动桥接交接；游戏处理完成、拒绝或超时后均停止当前桥接监听，不重试、不自动重连。用户仍可明确手动启动新桥接。
- 没有游戏回执或未观察到游戏离线时只记“下线未确认”，不把单纯断开桥接写成游戏退出成功。旧 Mod 不支持此能力，需更新 1.5.0。
- 此功能不退出 Minecraft 进程、不注销微软账号，也不控制其他 Mod 或启动器自己的自动重连功能。普通手动“断开桥接”仍只断开辅助通道。

## 关注与日志精简

- 取消手动“标为已读”按钮。打开关注页且窗口可见、聚焦时，自动标记已展示的当前服务器重要消息；后台、其他服务器及读取过程中后到的消息不会误清。
- 移除升级迁移提示、常驻通知验证信息和整个离线演练入口、IPC 与实现文件；旧版本发布记录保留。
- 沿用在线玩家中的监测名单，将该玩家发言、正文提到、@ 与相关封禁广播写入运行日志的玩家监测分类。明确发送者识别与正文关联记录分开，不把提及者误认成发送者，不增加额外说明界面。
- 桥接玩家聊天优先使用真实账号名；对旧 Mod 的 UUID 发送者，通过在线名单恢复账号名。
