# 芒果端辅助 V5.8

更新日期：2026-10-23（Asia/Singapore）。内部版本：5.8.0。桥接 Mod 保持 1.4.0，无需更新。

## 桥接不再自动获取收购价

- 原因在登录器的每日收购调度器：桥接进服后同样启用自动采集，等待约 15 秒后请求 Mod 执行 Shift+F；当天已自动采集成功、菜单打开或自动化暂停时会跳过，因此并非每次进服都出现。
- 桥接连接明确设置 `autoPurchaseEnabled: false`，自动调度遵守该策略。进服、重连、签到完成和跨天不自动打开收购菜单。
- 保留菜单能力协商及手动“获取收购价”/“重新获取”，手动不限次；关闭自动采集不会禁用手动读取，也不影响暂停自动化的保护逻辑。
- 独立连接仍保留原有每日自动采集；旧价格快照、账号服务器隔离、采集时间、自动及手动次数均不迁移或清空。
