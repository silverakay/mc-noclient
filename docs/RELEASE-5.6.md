# 芒果端辅助 V5.6

更新日期：2026-10-22（Asia/Shanghai）。内部版本：5.6.0。桥接 Mod 保持 1.4.0，无需更新。

## 独立连接菜单 stateId=-1 兼容

用户提供的日志显示：主菜单 ready、类型 5、状态号 -1、90/54 格、光标空、无待确认点击且唯一“小镇商店”入口已存在，但“可点击=否”。
这次阻塞已定位到软件自身 `ServerFeatures.canClick()` 中要求 stateId >= 0 的检查，不是菜单未打开或弹窗占用了后续操作。

- 兼容服务端实际下发的 -1 状态号，连同原有非负 signed-int32 状态号一起接受；其他负值、缺失、非整数和越界值仍拒绝。
- 与本地官方 Minecraft 26.2 实现一致，保留服务端最新状态号，点击包中原样回传 -1（VarInt 字节 `FF FF FF FF 0F`），不改成 0、不回退使用旧状态号。
- 保留就绪、容器类型、完整格数、窗口 token/revision、光标占用、300 ms 点击间隔、待确认锁与断线失效保护；不允许背包、窗口外或未知容器点击。
- 自动采集仍只导航、不出售物品、不进入鱼店；后台不弹窗策略不变。手动获取不限次、自动每天最多成功 1 次及旧数据兼容保留。
- 修复覆盖独立连接的自动导航及普通手动菜单点击；桥接此前使用原版游戏点击 API，本次不改动 Mod。
