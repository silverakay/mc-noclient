# 独立连接菜单点击

日期：2026-10-22。适用：5.0.0 菜单点击改进版，Minecraft 26.2 / 协议 776。

## 使用

在独立连接中，手动点击服务器聊天里的原始入口或发送自己已知的菜单命令。
服务器打开箱子式菜单并下发完整物品后，可普通左键或右键点击菜单格子；键盘 Tab 定位、Enter/空格执行左键。
例如公会签到中的“金币签到”，会提交该格子的原始容器点击，由服务器决定具体动作，无需知道隐藏命令。
关闭按钮及 Esc 正常关闭当前服务端菜单。

## 范围与保护

- 支持普通 1 至 6 行箱子菜单、普通 3x3 菜单；其他类型保留只读。
- 不支持背包点击、拖拽、Shift、数字键交换、批量转移、窗口外丢弃或自动签到格子。这不是垃圾桶物品投放功能。
- 不会按物品名称猜测命令，不会探测隐藏接口，不会将玩家聊天自动变成菜单操作。
- 每次手动点击绑定当前连接中的菜单随机令牌、窗口 ID 和菜单版本，窗口被复用、关闭、换服或断线后失效。
- 每次最多提交一个待处理点击，至少相隔 300 毫秒；直到完整菜单、相关槽位或光标收到服务器刷新前，禁止重复提交。
- 五秒没有相关刷新时显示结果未知，不自动解锁或重试；关闭再重新打开菜单后可重新查看。
- 使用真实 stateId，提交普通 PICKUP 点击；不做本地物品预测，不生成未知物品组件哈希，等待服务端权威槽位/光标纠正。
- 光标出现实际物品时暂停后续点击；关闭后物品去向以服务端正常关闭容器的处理为准。
- “点击已提交”不代表任务完成、签到成功或奖励到账；以服务端自然回复和菜单实际变化为准。
- 游戏桥接仍使用 Mod 1.2.0，本次未新增桥接菜单镜像或操作，不需要更换 Mod。

- 未连接真实服务器，未替用户签到或执行菜单任务，尚不保证目标服每个插件菜单的实际兼容性。
- 全量回归已通过；机械界面检查仍报告既有字号、对比度和发光阴影建议，本次没有扩大为全局重设计。
