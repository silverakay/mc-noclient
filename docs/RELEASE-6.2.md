# 芒果端辅助 V6.2

日期：2026-10-24（Asia/Singapore）。内部版本 6.2.0。未签名版本。桥接 Mod 沿用 1.5.0，Minecraft 26.2。

## 账号独立设置

- 设置按账号身份独立保存，包括桥接下线目标、消息动作、自动欢迎、红包触发与延迟、通知、显示、重连和连接模式；各账号内部仍区分服务器配置。
- 旧配置保留为迁移初值，各账号分别继承。修改某个账号不会修改其他账号或删除旧发布目录、凭据与配对数据。
- 双开保存通过文件锁完成读取、合并和原子替换，只写当前账号的配置，避免另一个窗口的旧副本覆盖其他账号。
- 设置窗口记录打开时的账号与服务器；切换后不能把旧表单误保存到新账号。
- 欢迎额度与零点命令每日去重记录也按账号隔离，避免一个账号执行后挡住另一个账号。旧记录只读复制一次，继承已有额度与去重状态，不重置当天已消耗次数。

## 重连固定原账号

- 当前账号选择保存在各进程内，不跟随另一窗口修改的共享缓存默认账号。
- 每次正版连接和后续重连绑定原账号 UUID。临时续期错误只重试原账号，凭据删除、失效或身份不匹配时停止并提示手动处理，不改用另一账号。
- 登录、账号切换、连接和重连互斥；退出后迟到的授权结果不能恢复连接。
- 账号缓存写入也采用文件锁，后台续期不修改其他窗口使用的默认账号选择。

## 多目标桥接下线

- 支持 1–16 位目标玩家，任一目标出现在游戏实时在线名单中即触发下线。旧单玩家规则自动兼容读取。
- 玩家选框支持在线名单多选、搜索、手动添加离线 ID、已选列表移除和数量显示。按 ID 忽略大小写去重，不混淆数字 0 与字母 O。
- 游戏桥接按实际游戏账号匹配本地设置；未缓存的游戏账号使用独立玩家配置，不套用另一个账号的设置。
- 仍使用 Mod 1.5.0 的能力协商、游戏会话和实时名单复核。多个目标同时在线只提交一次；下线后停止桥接与重连，不重复执行，不把缺失回执声称为成功。

## 交付边界

- 输出目录 `dist-6.2.0-unsigned`，产物名称明确标注未签名。保留 `build.forceCodeSigning: false`，不修改依赖版本、不安装证书或调整 Windows 安全策略。
- 公共包不含账号凭据、桥接配对秘密或私人数据快照。旧版目录及本机数据保留。
- 离线测试与隔离启动不等于真实服务器验收；双账号真实在线、游戏下线及其他 Mod 的重连行为仍需在目标环境验证。
