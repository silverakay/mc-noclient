# 芒果端辅助 V3.0（3.0.0）

发布日期：2026-10-12。配套桥接 Mod：1.2.0。仅提供本地 Windows x64 便携构建，不上传远程发布。

## 本次修改

- 删除自动钓鱼设置、状态显示、IPC、自动应用设置及桥接反射适配，不再出现“Auto-fishing mod is not installed”控制报错。
- 删除随软件打包的钓鱼资源与集成文档；原项目 JAR 归档到本次备份。旧配置中的 fishing 字段读取后丢弃，下次保存不再写回。
- 保留多账号、聊天渲染优化、红包十秒汇总与人数触发、Nan_Koi 留存、在线玩家、零点命令和真实 / 指令监测。界面其余布局不变。
- 桥接 Mod 1.2.0 保持原 Mod ID、协议版本 1 和配对文件。旧桥接可继续聊天和指令监测，桌面不再发送钓鱼控制请求。

## 使用

退出旧软件，运行 `dist-3.0.0/芒果端辅助-便携版-3.0.0.exe`。数据目录与账号库不变，无需重新添加服务器或重新配对。不要同时运行两份程序。

需要同步移除桥接中的钓鱼适配时，自行退出游戏，将旧桥接 JAR 移出 mods 后换成 `mc-noclient-bridge-1.2.0+26.2.jar`。同 ID 不能两份并存，保留 `config/mc-noclient-bridge.json`。

本次没有卸载游戏中独立安装的自动钓鱼 Mod，也没有操作真实账号凭据、服务器连接或配对文件。

## 验证边界

离线测试、隔离界面测试和最终包启动测试不会连接实服。桥接 JAR 检查包含元数据、类、调用接线及本地 26.2 描述符，不能代替整合包实际启动验证。
