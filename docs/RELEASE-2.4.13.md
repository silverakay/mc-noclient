# 2.4.13 页签切换性能修复

## 改动

- 聊天与运行日志不再每条消息立即读取完整滚动高度；同批消息合并到渲染帧，隐藏页不执行滚动和布局。进入待更新页后有限三帧修正富文本的实际高度，避免最新消息显示不全。
- 屏幕外消息通过 `content-visibility: auto` 跳过布局与绘制。聊天/日志仍各保留 800 条，不减少已有历史或磁盘在线记录；消息文字、颜色、悬停、复制、点击和筛选继续保留。
- 干净页签切换保留翻阅位置；用户滚动会取消迟到的底部修正。关闭自动滚动也适用于切换与窗口缩放；此前跟随底部时，缩放后继续显示完整最新消息。
- 连接状态不变时不再反复扫描历史动作按钮。手动点击等待、成功消费、自动领取已用、断开和旧会话失效仍立即更新。
- 在线名单按用户名复用节点，只更新变化的延迟/属性，增删/重排仍正确；搜索、点选查询与未知状态保持原行为。
- 约束右栏最小宽度，长消息不撑宽页面，底部修正不横向拖动整个窗口。不增加设置或按钮，不改网络、维护、零点命令、红包、欢迎或自动桥接规则。

## 验证

2026-10-10，25 个离线套件、12 项新增滚动/按钮行为测试及原界面 Playwright 回归通过。1060×720 / 860×600 模拟检查涵盖设置、维护、自动桥接、消息动作、名单、菜单、补全和溢出。所有夹具使用空账号/服务器或模拟 IPC，未连接目标服或发送实服测试命令。

压力数据：800 条各含 64 个富文本段的聊天、800 条日志，805 条消息截断仍保留最新 800 条；512 人延迟更新零名单子节点重建，连续 100 次稳定状态零动作按钮属性改写。最新消息底部、缩放、翻阅位置、关闭滚动、动作消费/失效与清空均验证。

最终基准报告位于 `dist/tab-performance-2.4.13.json` 和 `dist/tab-performance-2.4.13-electron.json`。这是本机模拟负载结果，不保证所有机器或未知卡顿因素均消除。布局性能只涉及渲染窗口，在线历史的数据查询没有改变。

在相同运行库中加载保留的 2.4.12 renderer/CSS 与新版对比，每版 4 轮三个页签切换。画面稳定指标包含等待 5 个渲染帧，不能等同于点击事件处理耗时。Electron 使用隔离的隐藏离屏窗口，不启动真实应用主进程或账号流程。

| 本机模拟指标 | 2.4.12 | 2.4.13 |
| --- | ---: | ---: |
| Electron 33.4.11 聊天切换事件平均 | 453.30 ms | 0.13 ms |
| Electron 聊天切换至 5 帧稳定平均 | 597.28 ms | 96.25 ms |
| Electron 同步收到 40 条消息 | 4198.70 ms | 2.70 ms |
| Electron 该批同步布局次数 | 40 | 0 |
| Edge 聊天切换至 5 帧稳定平均 | 278.35 ms | 42.35 ms |

新版的零同步布局不代表完全不需要布局，而是把工作延后并合并到浏览器渲染帧；自动滚动仍最多三帧完成。测试同时验证隐藏页无滚动、迟到帧取消、底部显示完整、翻阅位置、用户缩放和关自动滚动，不以删除历史换取速度。

保留原视觉系统。机械检测仍提示旧低对比度、较小字号、发光/阴影等问题，本次未整体重设计，也不宣称这些警告已消除。

备份：`backups/2.4.12-before-tab-performance-20261010-141854`，含旧源码 ZIP 与两个 EXE。新包独立放在 `dist-2.4.13`，不覆盖旧发布。使用既有 Electron 33.4.11，未更换桥接 Mod 或改用户配置。用户自行退出旧软件并启动新版本；运行时内存中的聊天/日志与原版本一样不跨退出保存，磁盘配置、在线记录、计数与配对不变。
