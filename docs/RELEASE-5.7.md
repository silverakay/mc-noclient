# 芒果端辅助 V5.7

更新日期：2026-10-23（Asia/Shanghai）。内部版本：5.7.0。桥接 Mod 保持 1.4.0，无需更新。

## 农作物名称与星级

- 独立连接原先仅加载原版中文语言表；服务端自定义物品使用 `item.customcrops.*` 翻译键，因缺少词条而显示原键，不是采集失败。
- 接入上一轮从本地整合包缓存提取的 `src/lang/customcrops_zh_cn.json`，共 105 条自定义物品词条，不依赖在线下载或游戏进程。
- 例如 `item.customcrops.gigantic_pineapple` 显示“巨型菠萝”，`item.customcrops.virelo_silver_star` 显示“幽碧兰（银星）”，`item.customcrops.cabbage_golden_star` 显示“卷心菜（金星）”。
- 支持 `custom_name`、`item_name`、嵌套文本组件，以及收购记录中的完整翻译键和 `customcrops:名称` 形式；保留自定义名称优先级、文本样式和原版词条。
- 收购星级按解析后的中文名称及品质说明识别；未收录的作物保持原键，不猜译、不把基础载体物品名称当作作物名称。
- 新采集记录保留原始翻译键及物品 ID，悬停名称可核对；聊天中的普通字面文本不进行字符串替换。

## 已有快照

- 读取已有快照时，在内存中转换已知翻译键并恢复对应星级；不需要重新采集。
- 不改写原快照文件，不改变价格、限量、销量、采集时间、服务器账号归属或自动及手动成功次数；兼容早期未区分计数来源的记录。
- 保留 V5.6 的菜单状态号 -1 兼容、只读后台采集、手动不限次及每日自动最多成功 1 次；不修改桥接 Mod 和私人数据。
